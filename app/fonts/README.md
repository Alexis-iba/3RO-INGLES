# Fuentes del proyecto

Baloo 2 y Nunito, subconjuntos latinos variables. Se conservaron los archivos originales descargados por next/font/google, sin modificar sus glifos, para que los libros y su exportación no dependan de una conexión con Google Fonts.

- Baloo 2: https://github.com/google/fonts/tree/main/ofl/baloo2
- Nunito: https://github.com/google/fonts/tree/main/ofl/nunito
- Ambas indican SIL Open Font License 1.1 en sus metadatos: https://openfontlicense.org/open-font-license-official-text/
